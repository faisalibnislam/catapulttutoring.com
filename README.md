# Catapult Tutoring homepage

A redesigned homepage for catapulttutoring.com, built as static HTML, CSS and JavaScript.

- `index.html` is the page. Serve the folder with any static server (for example `python3 -m http.server`) and open it in a browser.
- `HANDOFF.md` has the final copy, content hierarchy, design and motion system, search metadata, and the list of details that need client confirmation.
- `preview/` has full-page screenshots at 1440, 768 and 375 px.

The contact form validates input but is not connected to a backend yet, and says so when submitted.
